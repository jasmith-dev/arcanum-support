Arcanum support

Help for Arcanum: Visual Novel Suite on iPhone and iPad.

Get in touch

To report a problem or ask a question, open an issue on the project page. Inside the app, Help ▸ Report a problem gathers the details that help me find the cause; you see everything before you send it.

Common questions

Where are my projects kept? On your device, inside the app. Nothing is uploaded anywhere.

How do I keep a copy? File ▸ Back up, then choose Save to Files. Deleting the app deletes the projects kept inside it, so keep a backup.

How do I move a project to another device? Back it up to Files (or iCloud Drive), then on the other device use File ▸ Open.

Does it need the internet? No. Arcanum works fully offline.

Privacy

Arcanum collects nothing. Read the privacy policy.
